# 2.13 remaining API — návrh (Fáze 10a)

Stav: **APPROVED** (architekt, delegováno vlastníkem 2026-11-22). Vše aditivní, výchozí hodnoty
a výchozí DOM beze změny; v CHANGELOG 2.13.0 žádná položka Breaking/Migration.

## (a) SELECT-TYPES — TmSelect plná podpora typů
- `HandleChangeAsync`: za existující větve fallback `BindConverter.TryConvertTo<TValue>(raw, CultureInfo.InvariantCulture)`.
- `FormatOptionValue` symetricky: `DateOnly` `yyyy-MM-dd`, `TimeOnly` `HH:mm:ss.FFFFFFF`, `DateTime`/`DateTimeOffset` `O`,
  `bool` `true`/`false`, ostatní `IFormattable` invariantně. Round-trip format → parse == hodnota je testovaný kontrakt.
- Nepřevoditelný raw: `ValueChanged` se nevolá (žádný tichý `default`); v DEBUG log přes volitelný `ILogger<TmSelect<TValue>>`.
- Žádný nový parametr. Trim: 0 nových IL20xx (publish WASM, TrimMode=full).

## (b) OPTION-LANG — Lang u voleb + value radia
- `RadioOption` a `SegmentedOption`: init property `string? Lang` (positional konstruktor beze změny).
- `TmRadio`: `[Parameter] string? Lang` → `lang` na `.tm-radio-text`; nativní `<input type=radio>` dostane
  `value` = invariantní formát hodnoty (stejný helper jako TmSelect, sdílený interní `OptionValueFormatter`).
- `lang` se vykreslí jen pro neprázdnou hodnotu. Redundantní `aria-checked` na nativním radiu se odstraňuje (oprava ARIA in HTML, ne breaking).

## (c) UPLOAD-HOST-CTS — TmUploadItem host-owned cancellation
- `public CancellationToken BeginAttempt()` — položka vytvoří a vlastní nový CTS, starý zruší/disposuje, resetuje příznak zrušení.
- `public Func<TmUploadItem, Task>? ResumeAction { get; set; }` (dnes internal → veřejný setter).
- `TmUploadItem : IDisposable`. Interní komponenty (TmFileUploadProgress, TmFileDropZone, TmAttachmentManager) používají jen `BeginAttempt`.
- `Cts`/`Source` zůstávají internal.

## (d) VALIDATION-FIELD-ID — TmValidationSummary identita pole
- `public sealed record ValidationSummaryItem(FieldIdentifier Field, string Message)` (namespace `Tempo.Blazor.Components.Forms`).
- Parametry: `Func<ValidationSummaryItem,string>? GroupItemsBy`, `EventCallback<ValidationSummaryItem> OnItemClick`,
  `RenderFragment<ValidationSummaryItem>? ItemTemplateWithField`.
- S kterýmkoli novým parametrem: sběr per pole, deduplikace podle (Field, Message). Kombinace starého a nového stejného druhu
  (GroupBy+GroupItemsBy, OnMessageClick+OnItemClick, ItemTemplate+ItemTemplateWithField) → `ArgumentException` v `OnParametersSet`.

## (e) PICKER-FIELD-PARITY — TmDatePicker/TmDateTimePicker
- `ReadOnly` (vzor TmTimeInput: fokusovatelný trigger, neotevře se klikem/Enter/Alt+Down, bez clear, `aria-readonly`, třída
  `tm-date-picker--readonly` / `tm-datetime-picker--readonly`, bez disabled barev), `AriaDescribedBy` + kaskáda TmFormField
  (vzor `TmSelect.DescribedByCore`), `RenderFragment? LabelTrailing` (vzor TmSelect, třída `tm-input-label-trailing`).
- Guard `FieldLabelTrailingGuardTests`: každá komponenta s `Label` a blokovým popiskem v Inputs/Pickers/Dropdowns má `LabelTrailing`;
  výjimky TmCheckbox, TmToggle, TmRadio (inline popisek).
- Doplňky z completion reportu (49294dd9, c0a1f4bb), vše opt-in:
  - výška/zarovnání časového pole = výška datového pole; clear „×“ má rezervované místo (žádný posun) — vizuální oprava, bez API;
  - prázdný picker neukazuje `00 : 00`, ale placeholder času (oprava; hodnota null zůstává null);
  - `bool AllowTypedDate` (default `false`) — psané datum parsované v `CurrentCulture` (krátký formát), chybný vstup = neplatný stav, ne tichý reset;
  - `DateTimePickerDefaultTime DefaultTime` (enum `Midnight` default | `Now`) — čas při prvním výběru dne na prázdném pickeru; `Now` z injektovaného `TimeProvider` (fallback `TimeProvider.System`).

## (f) TABS-STICKY-TOKENS — TmTabs
- `--tm-tabs-sticky-z-index: 5` a `--tm-tabs-edge-shadow-color: var(--tm-border-color)` na `:root` v tokens.css; čteno bez fallbacku.
- Krycí vrstvy scroll-edge: plná krycí barva v šířce `--tm-tabs-edge-shadow-size`, pak přechod → nepřetékající pás bez stínu.
